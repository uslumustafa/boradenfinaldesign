## 1. Durum özeti

- **Sayfa geçişi düzeltmesi (2026-10-09, proje sahibinin bildirdiği hata):** Hizmetler'de bir bağlantıya tıklanınca 3B geçiş bazen geliyor bazen gelmiyordu. Neden: noktaların dışarı akışı kare başına en çok 0,1 sn sayılıyordu; kareler takılınca (ağır sayfa, kahraman ekran dışındayken duran dünyanın yeniden başlaması, sayfa değişimi, yavaş GPU) noktalar ekran dışına varamadan içerik değişiyordu. Yeni sayfanın sahne hedefi de ancak bir sonraki karede veriliyordu; «noktalar dışarıda» penceresi kaçınca yeni şekil içeri akmak yerine eski şekil geri toplanıp çözülerek (ya da süzülerek) değişiyordu. Düzeltme: akış **saatle** ilerler (`world.js › surgeAtTime`; çıkış 450 ms, giriş 1050 ms; giriş, yeni şekil üretilip ilk kez çizildikten sonra sayılır; yön değişiminde konum sıçramaz); `surge(true)` noktaların dışarı varmasına kalan süreyi döndürür, yönlendirici o kadar bekler; yönetmen sahne hedefini mount anında verir (`behaviors.js › director`), böylece yeni şekil her seferinde noktalar dışarıdayken oturur ve giriş ondan sonra başlar; geçiş kareleri uyarlanabilir kalite ölçümüne girmez (geçişler efekt kademesini kendiliğinden düşürmesin). Yeni denetim `tests/transition.e2e.mjs` (`npm run test:e2e` içinde): dizin satırı, kırıntı, alan kartı, alan → hizmet, Hizmetler mega menüsü ve üst menü — olağan ve yapay yavaş (≈ 180 ms) karelerle 12'şer gezinme; WebGL uniform'larından çıkışın tamamlandığını, çözülme/süzülme olmadığını ve girişin çizildiğini ölçer (eski sürümde 13 hata, düzeltmeyle 0). ## 2. Çalıştırma

```
npm install                 # bir kez
npm run dev                 # derle + sun (http://127.0.0.1:4181) + src/ ve scripts/ değişince yeniden derle
npm run build               # dev derleme (hata yalıtımlı: bir sayfa bozulsa diğerleri üretilir; hatalar konsola/kırmızı sayfaya yazılır)
npm run build:prod          # prod: dist/'i siler, küçültür, HER hatada durur
npm run build:assets        # yalnızca CSS/JS/yazı tipi/görsel (Wagtail hattı için; BORADEN_DIST ile hedef klasör)
npm run serve               # dist/'i sunar (PORT, BORADEN_DIST ortam değişkenleri); vercel.json kurallarını da uygular
```

Yazı tipleri depoda hazırdır (`src/assets/fonts/`); yalnızca aile, ağırlık ya da karakter kümesi değişirse yeniden üretilir: `npm run fonts` (Python 3 + `pip install fonttools brotli`; `PYTHON` başka yorumlayıcı seçer). Betik (`scripts/tools/subset-fonts.py`) Fontsource'un latin ve latin-ext dosyalarını yüz başına tek dosyada birleştirir, Türkçe içeriğin karakterlerine indirir ve adına içerik özeti ekler (aynı girdiden hep aynı dosya: ad yalnızca içerik değişince değişir); `00-fonts.css` ile `fonts.json` (önyükleme adları, `font_url`) da yeniden yazılır. Sayfa başına kullanılan her yüz için tek dosya iner: 6–9 dosya, ≈ 124–191 KB (önceden 12–16 dosya, ≈ 221–309 KB).

Yerel sunucu (`scripts/serve.mjs`) `vercel.json`'daki `trailingSlash`, `redirects` ve `headers` kurallarını (has/missing koşullarıyla) yayındaki gibi uygular: CSP, noindex, eski site yönlendirmeleri yerelde de görülür; dosya yolları Vercel gibi büyük/küçük harfe duyarlıdır. `BORADEN_HOST=www.boraden.com.tr` canlı alan adının başlıklarını öykünür (noindex yok, katı CSP). Önbellek başlığı yerelde `no-cache` kalır (yayındaki kurallar: `docs/VERCEL.md`; sürümler `?v=` = içerik özeti, `scripts/build.mjs › asset_v, search_v`).

Mac uyuyunca/yeniden başlayınca sunucu gider; yeniden `npm run dev`. `BORADEN_DIST=/yol` çıktı klasörünü değiştirir (paralel çalışmalar için).
